# Third-party and generated assets

Everything the simulations load at run time is served by this application from
`public/`. Nothing is hot-linked, so the lab works on the school network
without internet once the files are in place.

Rebuild or re-fetch with:

```bash
npm run assets       # MediaPipe WASM + hand model + HDRI (runs after npm install)
npm run build:model  # resistor.glb from lib/resistorGeometry.ts
```

## Resistor lab (`public/simulations/resistor/`)

| File | What it is | Source | Licence | Size |
| --- | --- | --- | --- | --- |
| `hdr/studio_small_09_768.hdr` | Neutral studio environment for reflections and fill light | "Studio Small 09" by Sergej Majboroda, Poly Haven, <https://polyhaven.com/a/studio_small_09>, 1k file downsampled to 768 × 384 by `scripts/fetch-assets.mjs` | CC0 1.0 (public domain) | 1.13 MB |
| `models/resistor.glb` | The 1/4 W carbon-film resistor: meshes `body`, `lead_0`, `lead_1`, `band_0`…`band_3`, millimetres, axis +Y, meshopt-compressed | Generated by this project, `scripts/build-resistor-glb.ts` | Same as the project | 168 KB |
| `mediapipe/wasm/vision_wasm_internal.{js,wasm}`, `vision_wasm_nosimd_internal.{js,wasm}` | MediaPipe Tasks Vision runtime for opt-in hand control | npm `@mediapipe/tasks-vision`, copied from `node_modules` | Apache-2.0 | ≈ 22 MB |
| `mediapipe/hand_landmarker.task` | Hand landmark model (float16) | <https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task> | Apache-2.0 | 7.8 MB |

The MediaPipe files are only requested after a student presses "Try hand
control". They are not part of the 3D payload below.

### Generated at run time (no download)

These are drawn on a `<canvas>` in the browser by
`resources/js/simulations/resistor/lib/textures.ts`, seeded so every student
sees the same thing:

- ceramic lacquer colour, roughness and bump maps (512, 1024 or 2048 px wide by device);
- brushed roughness for the tinned leads;
- breadboard top (holes, rails, moulded numbers);
- anti-static mat;
- multimeter face and its live LCD (seven-segment digits drawn as shapes, no font file).

### Payload on the 3D stage

| Part | Transfer size |
| --- | --- |
| 3D JavaScript chunk (three.js, R3F, drei, the scene) | ≈ 273 KB gzip |
| `resistor.glb` | 168 KB |
| HDRI | 1.13 MB (≈ 0.9 MB gzip if the web server compresses `.hdr`) |
| **Total** | **≈ 1.6 MB, once, then cached** |

Pages without a simulation download none of this. The light 2D bench downloads
only the island bundle (≈ 109 KB gzip, shared with the 3D stage).

The landing page reuses the same model, HDRI and chunks for its hero, but only on
capable devices: the landing entry itself is ≈ 1 KB, and phones, low-power PCs and
browsers without WebGL download none of the 3D payload (see docs/SIMULATIONS.md,
"The landing page hero").
